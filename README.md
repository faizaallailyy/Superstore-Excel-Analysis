# 📊 Superstore Performance Analysis (Excel End-to-End Project)

## 📌 Project Overview

This repository contains an **end-to-end data analysis project built entirely in a single Microsoft Excel file**, using the **Superstore dataset**. The project demonstrates the complete analytical workflow from **raw data exploration and cleaning**, to **pivot table analysis**, **dashboard visualization**, and **business insights & recommendations**.

The purpose of this project is to showcase **practical Excel-based data analysis skills** for **Data Analyst / Business Intelligence** roles.

---

## 🎯 Project Objectives

* Analyze sales and profit performance over time (2014–2017)
* Identify factors driving profit volatility despite strong sales growth
* Evaluate the impact of discounts on profitability
* Compare performance across regions, categories, and sub-categories
* Deliver clear, data-driven business recommendations

---

## 🧩 Workbook Structure (Single Excel File)

All analysis is contained in **one Excel workbook** with the following sheets:

1. **Raw Data**
   Original dataset with no modifications.

2. **Data Clean**
   Data cleaning and preparation, including formatting, filtering, and calculated fields.

3. **Pivot Table**
   Pivot tables used to analyze sales, profit, discount impact, and performance by region, category, and sub-category.

4. **Dashboard**
   An interactive Excel dashboard featuring KPIs, trends, and visual comparisons.

5. **Analysis**
   Written insights summarizing key findings derived from the dashboard and pivot analysis.

---

## 📈 Dashboard Highlights

The Excel dashboard presents:

* Key KPIs: Total Sales, Total Profit, Profit Margin, Total Orders, Average Order Value
* Sales and Profit trends over time
* Sales vs Profit comparison by region
* Profitability by category and sub-category
* Discount impact on profit
* Top customers and shipping mode profitability

---

## 🔍 Key Insights Summary

* Total sales reached **$2.3M**, showing consistent growth over four years.
* Profit totaled **$286K** with an average margin of **12.47%**, but with high volatility.
* The **West region** leads in both sales and profit, while the **South region** underperforms in profitability.
* High-sales sub-categories (e.g., Phones and Chairs) do not always generate high profit.
* Discounts above **30%** almost always result in losses, driving over **26% negative-profit orders**.
* Copiers and Accessories deliver the strongest profit despite lower sales volume.

---

## 💡 Business Recommendations

* Shift focus from revenue growth to **profit-based performance metrics**.
* Limit discount rates to a maximum of **30%** and replace deep discounts with alternative incentives.
* Prioritize high-margin sub-categories such as **Copiers and Accessories**.
* Improve underperforming regions by applying best practices from top-performing regions.
* Encourage profitable shipping modes as value-added services.
